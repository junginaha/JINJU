# 진주 — 앱인토스 개발 브랜치

앱 ID: `jinju`. 이 문서는 개발 준비용이며 앱인토스 등록·심사 완료를 뜻하지 않습니다.

## 구현 계획
- 운영 사이트와 별개로 토스 WebView 진입 경로를 구성합니다.
- 기존 공개 GET `/api/posts?limit=10&sort=latest`를 읽기 전용으로 활용합니다.
- 데이터베이스 미연결/오류 시에도 화면이 무너지지 않도록 처리합니다.
- 로그인, 글쓰기, 자동 댓글, 외부 공유, 광고는 1차 MVP에서 제외합니다.
- 앱인토스 SDK 버전과 실제 빌드 규격은 공식 개발 문서와 샌드박스로 검증한 후 적용합니다.

## 보호 조건
- main 병합, PR, 배포, 기존 API 변경 금지
- 개인정보·운영자 비밀값을 토스 클라이언트에 넣지 않음
- 댓글과 반응의 실제 데이터 출처를 명시하고 가상 이용자 반응을 만들지 않음
