# 진주.kr 참여 전환 실행계획

기준일: 2026-11-17 KST
목표: 읽기만 하는 전시형 사이트에서 자기 생각을 남기고 다시 찾아오는 공간으로 전환한다.

## 확인한 사실

- 11월 17일 첫 복구 배포 후 공개 글 681편. 누적 수량을 실제 이용자 수로 해석하지 않는다.
- 최근 제작 글 3편은 완독과 북클럽, 송년회 귀가, 답장 시점에 관한 질문이다.
- Metricool 연결 조회 결과 소셜 채널이 하나도 연결되지 않았다. 외부 발송·게시를 완료했다고 보고하지 않는다.
- 웹의 lib/track.ts는 Toss용 후크만 호출하며 일반 웹에서는 분석 데이터가 수집되지 않는다. UTM을 붙이는 것만으로 유입 측정이 완료되지는 않는다.
- 이번 제작 대화는 게시글별 10편, 총 30편이다. 게시물의 논점을 이어가는 대화 콘텐츠로 구성한다. 실제 이용자 경험담·참여·전환 실적에서 제외한다.
- 새 글의 실제 좋아요를 인위적으로 높이지 않는다. 추천을 위한 인위 숫자보다 실제 작성 행동을 확인한다.

## 이번에 실행한 작업

1. 최근 3편에 서로 다른 논점의 대화 10편씩 작성하고 본문마다 자연스러운 연결 구성.
2. /start 첫 방문 안내: 주제 선택 → 관련 글 읽기 → 내 생각 보태기.
3. /?write=1 링크로 인트로를 거치지 않고 기존 글쓰기 창을 연다. 방문자의 입력 초안을 덮어쓰거나 자동 게시하지 않는다.
4. /start의 검색 설명·공유 정보·사이트맵 등록. 검색 노출이나 AI 인용 성공으로 간주하지 않는다.
5. 매일 기존 일일 업무에서 실제 게시·댓글·홍보 연결 상태를 확인하도록 통합. 같은 콘텐츠는 재게시하지 않는다.

배포·운영 검증 결과는 이 문서에 연결되는 커밋의 검증 기록과 일일 업무 인수인계를 따른다. 문서 작성만으로 운영 반영 완료라고 취급하지 않는다.

## 첫 2주: 한 사람에게 한 가지 행동만 요청

핵심 고객: 책과 북클럽 이야기를 할 사람, 관계에서 작은 고민을 말하고 싶은 사람.
첫 유통 경로: 기존 Qsapiens 북클럽과 onedaybooks19의 실제 연결 계정.
새 유료 광고나 신규 플랫폼 가입, 무차별 DM은 진행하지 않는다.

### 1~3일: 한 질문으로 시작

- /start를 공통 안내 주소로 사용한다.
- 북클럽에는 완독과 참석 주제 한 편만 안내한다. 클릭 뒤에는 해당 글로 바로 보낸다.
- CTA는 ‘여러분 모임의 규칙 한 가지를 댓글로 남겨주세요’ 하나로 좁힌다.
- 실제 댓글에는 먼저 맥락을 읽고 답한다. 없는 경험·경력·실제 이용자 수를 만들지 않는다.
- 소셜 연결이 완료되면 연결된 정확한 계정과 최근 게시 이력을 대조한 뒤 아래 완성 문안을 게시한다. 연결 전 중복 예약 금지.

### 4~7일: 반응이 생긴 주제 확장

- 실제 의견이 붙은 주제에서 후속 질문 1편을 만든다. 실제 사연의 인용·재사용은 별도 허락 없이 하지 않는다.
- 송년회 귀가 주제를 두 번째 실험으로 소개한다. 앞 주제와 하루에 동시에 홍보하지 않는다.
- 반응 없는 주제는 제목·CTA를 한 번 조정한다. 새 글 대량 생산으로 대신하지 않는다.
- 매일 예시 댓글과 실제 댓글을 나누어 기록한다.

### 8~14일: 작성과 재방문 확인

- 글쓰기 초대는 ‘상황 → 마음 → 질문’ 세 문장 형식을 안내한다.
- 실제 글이 올라오면 안전 검수·공개 여부를 확인하고 그 글에 관련된 정성 있는 답변을 우선한다.
- 모임에서 한 번 나눈 질문을 다음 모임 전에 다시 읽어보도록 안내한다. 재방문율은 분석 데이터가 없으므로 임의 수치화하지 않는다.
- 실제 새 글 5편, 실제 댓글 10편을 14일 실험의 내부 목표로 둔다. 성과 보장이나 달성 사실이 아니다. 예시 콘텐츠·본인 작성·테스트는 제외한다.
- 목표 미달이면 배포 부족/도착 후 혼란/작성 어려움 중 확인된 막힘부터 고친다. 외부 노출을 못 했다면 서비스 수요가 없다는 결론을 내리지 않는다.

## 11월17일 밤 디자인·문체 수정

사용자 요청에 따라 새 중간 안내 화면을 제거한다. /start는 기존 글쓰기 창 /?write=1로 연결하는 호환 주소만 유지한다. 반복 표기와 설명을 빼고 최근3편의 대화30개를 공감→반론→조율→유머→결론의 흐름으로 다시 다듬는다. 홍보물에도 반복 표기를 넣지 않는다. 단일 제작 출처의 콘텐츠와 실제 이용자 유입·참여 실적은 내부 기록에서 분리한다.
